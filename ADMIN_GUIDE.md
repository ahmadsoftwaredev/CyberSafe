# CyberSafe – Admin Guide

## 1. Introduction

The CyberSafe Admin Guide explains how administrators can manage the website's cybersecurity content and quizzes.

Administrators have access to additional management features that are not available to regular users.

## 2. Administrator Login

To access the administrator dashboard:

1. Open the CyberSafe website.
2. Navigate to the Login page.
3. Enter the administrator account credentials.
4. Click the Login button.
5. After successful authentication, the system redirects the administrator to the Admin Dashboard.

**Note:** Administrator access is controlled through role-based access control (RBAC).

## 3. Admin Dashboard

The Admin Dashboard provides an overview of the CyberSafe application and access to administrative functions.

Administrators can access:

- System overview and statistics
- Manage Articles
- Manage Quizzes
- Open Dashboard

The dashboard provides a central location for managing cybersecurity learning content.

## 4. Managing Security Articles

Administrators can manage the cybersecurity articles displayed in the Security Tips section.

### 4.1 Viewing Articles

1. Log in using an administrator account.
2. Open the Admin Dashboard.
3. Select **Manage Articles**.
4. View the available security articles.

### 4.2 Adding a New Article

1. Open the Manage Articles section.
2. Select the option to add a new article.
3. Enter the article title.
4. Select the appropriate category.
5. Enter the article content.
6. Submit the form to save the article.

After successful submission, the new article becomes available in the Security Tips section.

### 4.3 Editing an Article

1. Open Manage Articles.
2. Locate the article you want to update.
3. Select its Edit option.
4. Modify the required information.
5. Submit the form to save the changes.

### 4.4 Deleting an Article

1. Open Manage Articles.
2. Locate the article you want to remove.
3. Select the Delete option.
4. Confirm the deletion if prompted.

The selected article will be removed from the system.

## 5. Managing Quizzes

Administrators can create and manage cybersecurity quizzes.

### 5.1 Viewing Quizzes

1. Open the Admin Dashboard.
2. Select **Manage Quizzes**.
3. Review the available quizzes.

### 5.2 Creating a Quiz

1. Open Manage Quizzes.
2. Select the option to add a quiz.
3. Enter the quiz title.
4. Select its category.
5. Provide a description.
6. Configure its active status.
7. Submit the form to create the quiz.

### 5.3 Editing a Quiz

1. Open Manage Quizzes.
2. Locate the quiz you want to update.
3. Select Edit.
4. Update the required quiz information.
5. Save the changes.

### 5.4 Deleting a Quiz

1. Open Manage Quizzes.
2. Locate the quiz you want to remove.
3. Select Delete.
4. Confirm the action if prompted.

The quiz will be removed from the system.

## 6. Managing Quiz Questions

Administrators can add, edit, and delete questions associated with quizzes.

### 6.1 Viewing Questions

1. Open the Manage Quizzes section.
2. Select the relevant quiz.
3. Navigate to its question management section.
4. Review the existing questions.

### 6.2 Adding a Question

1. Open the question management section for the selected quiz.
2. Select Add Question.
3. Enter the question text.
4. Provide the available answer options (A, B, C, and D).
5. Select the correct answer.
6. Enter an explanation if required by the form.
7. Submit the form to save the question.

### 6.3 Editing a Question

1. Locate the question you want to modify.
2. Select Edit.
3. Update the question text or answer options.
4. Verify the correct answer.
5. Save the changes.

### 6.4 Deleting a Question

1. Locate the question.
2. Select Delete.
3. Confirm the action if prompted.

The selected question will be removed from the quiz.

## 7. User and Administrator Permissions

CyberSafe uses role-based access control to restrict administrative functionality.

**Regular Users:**
- Access the user dashboard.
- Explore security tips.
- Use the Password Checker.
- Use the URL Checker.
- Attempt available quizzes.
- View their quiz results and history.

**Administrators:**
- Access the Admin Dashboard.
- Manage security articles.
- Create, update, and delete quizzes.
- Manage quiz questions.
- Access regular user features where permitted.

Unauthorized users cannot access protected administrative pages.

## 8. Security Best Practices for Administrators

Administrators should:

- Keep administrator credentials confidential.
- Use a strong and unique password.
- Avoid sharing administrator accounts.
- Verify article content before publishing.
- Review quiz questions and correct answers before making quizzes available.
- Log out after completing administrative tasks.
- Avoid accessing the administrator dashboard from untrusted devices.

## 9. Troubleshooting

If an administrator encounters an issue:

- Verify that the correct administrator credentials are being used.
- Ensure that the account has the administrator role.
- Check that required form fields are completed.
- Refresh the page if content does not load correctly.
- Contact the system developer if an administrative operation fails.
