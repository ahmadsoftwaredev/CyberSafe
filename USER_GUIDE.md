# CyberSafe – User Guide

## 1. Introduction

CyberSafe is a cybersecurity awareness and protection website designed to help users improve their understanding of online security.

It provides useful security information, interactive tools, and quizzes to help users develop safer online habits.

This guide explains how to use the main features of CyberSafe as a regular user.

## 2. Accessing CyberSafe

1. Start the CyberSafe application on your local system or open its deployed website.
2. Open the website in your browser.
3. The homepage provides an introduction to CyberSafe and its available features.
4. Register or log in to access the website's protected features.

For a locally running application, open:

`http://127.0.0.1:5000/`

## 3. Creating a User Account

To create a new account:

1. Open the CyberSafe homepage.
2. Click the **Get Started** or **Register** option.
3. Enter the required registration information.
4. Submit the registration form.
5. After successful registration, proceed to the login page.

Newly registered accounts are assigned the normal user role.

## 4. Logging In

To access your account:

1. Open the Login page.
2. Enter your registered email or username, according to the login form.
3. Enter your password.
4. Click the Login button.

After successful authentication, regular users are redirected to their user dashboard.

## 5. User Dashboard

The user dashboard provides access to the main CyberSafe features.

From the dashboard, users can access:

- Security Tips
- Password Checker
- URL Checker
- Cybersecurity Quizzes
- Quiz History and Performance

The available navigation options allow users to move between different sections of the website.

## 6. Exploring Security Tips

The Security Tips section provides cybersecurity-related information to help users stay safe online.

To explore security tips:

1. Log in to your CyberSafe account.
2. Open the Security Tips section.
3. Browse the available security articles.
4. Select an article to view its complete details.

Users can read articles to learn about cybersecurity threats, safe browsing practices, and online protection.

## 7. Using the Password Checker

The Password Checker helps users evaluate the strength of a password.

To use this tool:

1. Open the Password Checker from the dashboard or Tools menu.
2. Enter a password in the provided input field.
3. Review the displayed password strength information.
4. Adjust the password if necessary.

Users should create strong passwords that combine uppercase letters, lowercase letters, numbers, and special characters.

**Important:** Avoid entering your actual account passwords into websites or tools that you do not trust.

## 8. Using the URL Checker

The URL Checker helps users assess a submitted web address for potentially suspicious characteristics.

To use the tool:

1. Open the URL Checker from the dashboard or Tools menu.
2. Enter the URL you want to check.
3. Submit the URL.
4. Review the displayed result.

**Important:** The URL Checker provides an automated assessment and should not be treated as a guarantee that a website is safe. Always verify website addresses and avoid sharing sensitive information with suspicious websites.

## 9. Taking Cybersecurity Quizzes

CyberSafe provides quizzes to help users test their cybersecurity knowledge.

To attempt a quiz:

1. Open the Quizzes section.
2. Browse the available quizzes.
3. Select an active quiz.
4. Read each question carefully.
5. Select the appropriate answer.
6. Submit your answers to complete the quiz.

After submission, the system displays the quiz result.

## 10. Viewing Quiz Results

After completing a quiz, users can view their performance.

The result page displays information such as:

- Overall score
- Correct answers
- Total questions
- Percentage achieved
- Answer review and explanations, where available

This information helps users understand their performance and identify areas that need improvement.

## 11. Viewing Quiz History

Users can access their previous quiz attempts through the Quiz History section.

The quiz history allows users to review their previous results and monitor their learning progress.

Users can use this information to identify improvement over multiple quiz attempts.

## 12. Logging Out

To securely end a session:

1. Locate the Logout option.
2. Click Logout.
3. The system ends your authenticated session and redirects you to the homepage.

Always log out when using CyberSafe on a shared or public computer.

## 13. Security Recommendations

For a safer online experience, users should:

- Use strong and unique passwords.
- Avoid clicking suspicious links.
- Verify website addresses before entering personal information.
- Never share passwords or sensitive account information.
- Keep browsers and operating systems updated.
- Read cybersecurity articles regularly.
- Practice cybersecurity knowledge through quizzes.
- Log out after using shared devices.

## 14. Support and Troubleshooting

If you experience an issue while using CyberSafe:

- Make sure you are logged in before accessing protected features.
- Verify that your login credentials are correct.
- Refresh the page if content does not load properly.
- Check your internet connection if external resources are unavailable.
- Contact the project administrator if the issue continues.
